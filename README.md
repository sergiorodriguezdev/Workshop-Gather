# _Gather_

## Description

This was my first introduction to [Replit](https://replit.com) and followed the Quickstart guide found [here](https://docs.replit.com/build/your-first-app). Users can sign up for an account and securely save their RSVPs.

To extend its functionality, I created a connection with [RSVP Pulse](https://github.com/sergiorodriguezdev/RSVP-Pulse) where updates are pushed via a webhook so workshop organizers can keep track of sign-ups.

## Technologies Used

- Replit
- Clerk
- PostgreSQL
- Webhooks
